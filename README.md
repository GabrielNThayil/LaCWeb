#  La Couronne Café - Where Mood Meets Flavor 

## Project Purpose
A premium digital experience where every visit tells a story – through curated mood-based recommendations, we transform the way you discover your perfect café experience. Whether seeking focus, comfort, or indulgence, La Couronne adapts to your emotional palette.

*Cited files:*
- `components/MoodRecommender.tsx` (core experience logic)

##  Key Features

### 1. Mood-Based Navigation 
**6 expertly curated mood profiles**:
-  Need Focus
-  Cosy & Warm
-  Treat Yourself
-  Productive Morning
-  Creative Session
-  Something New

Each with:
- Custom iconography
- Tailored drink/food pairings
- Personalized descriptions

### 2.  Intelligent Personalization
-  Learns from user preferences
-  Considers visit history
-  Respects dietary restrictions
-  Highlights favorite items

### 3.  Premium UI Experience
-  Dark mode support (default theme)
-  Smooth transitions & microinteractions
-  Mobile-first responsive design
-  Accessibility-first implementation

### 4.  Virtual Menu Explorer
-  Coffee & specialty drinks
-  Desserts & pastries
-  Light bites & brunch options
-  Seasonal specials

##  Getting Started

### Local Development
1. **Clone**:
```bash
 git clone https://github.com/GabrielNThayil/LaCWeb.git
```
2. **Setup**:
```bash
 npm install
```
3. **Configure** `.env.local`:
```env
 NEXTAUTH_SECRET=your_secret
 NEXTAUTH_PROVIDER=your_auth_provider
 ```
4. **Run**:
```bash
 npm run dev
```
